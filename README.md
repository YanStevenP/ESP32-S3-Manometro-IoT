# Dispositivo IoT com IA Embarcada para Monitoramento de Manômetros

Este repositório contém os materiais de suporte ao trabalho de conclusão de curso (TCC) de Engenharia Mecatrônica da UFRN.

## Conteúdo
- `firmware/`: Código C++ desenvolvido para ESP32-S3.
- `dataset/`: Amostras de imagens utilizadas no treinamento.
- `models/`: Modelo treinado (.h5) e quantizado (.tflite).
- `cad_mechanics/`: Modelos 3D do suporte impresso.

## Referência
Pontes, Y. S. N. (2026). *Dispositivo IoT com IA Embarcada para Monitoramento Remoto de Manômetros Analógicos via Visão Computacional*. Universidade Federal do Rio Grande do Norte.
